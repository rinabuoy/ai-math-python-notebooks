# Math for AI / ML / Data Science — Python lessons and labs

Runnable Jupyter notebooks that accompany the primer *Mathematical Foundations for AI, Machine Learning and Data Science* (prepared by Rina Buoy, PhD). Every notebook runs in **Google Colab** with no setup — click a badge. All libraries used (NumPy, SciPy, SymPy, pandas, Matplotlib, scikit-learn) are pre-installed in Colab.

* **69 lessons** — one per concept: demonstration cells with output, a "Cambodian textbook corner", exercises and solutions.
* **8 labs** — multi-topic practice that combines several lessons.

Order of study: lessons 1–7 (foundations) → 8–27 (linear algebra) → 28–35 (calculus) → 36–47 (learning from data) → 48–67 (probability and statistics); 68–69 are summation and recurrences (best read with Lesson 1).

* Three notebooks (Lab C, Lab H and lesson 52) can use the public course data files if you place them in a `data/` folder; otherwise they automatically use a small synthetic stand-in, so everything still runs.
* Try each exercise before opening the *Solutions* cells at the bottom.
